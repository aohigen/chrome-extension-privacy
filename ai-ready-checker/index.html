Chrome拡張機能「AI対応チェッカー by 3PT」

最終更新日：2026年7月31日

要約：本拡張機能は、いかなる個人データも収集・保存・外部送信しません。すべての判定はあなたのブラウザ内だけで完結し、外部のサーバーへデータを送ることは一切ありません。アクセス解析（アナリティクス）やトラッキングも行いません。

1. 本拡張機能について

「AI対応チェッカー by 3PT」（以下「本拡張機能」）は、現在表示しているWebページが生成AIのAI検索（ChatGPT検索・Claude・Perplexity 等）に読み取られる状態かを、ツールバーのバッジ色で示すツールです。株式会社サードパーティートラスト（以下「当社」）が提供します。

2. 取得・処理する情報

本拡張機能は、判定を行うために、Chromeで読み込みが完了した判定対象のHTTPSページに関する以下の情報を、その場で読み取ります。これらはすべてあなたのブラウザ内での判定のためだけに使われ、処理後にブラウザの外へ出ることはありません。

読み取る情報目的
現在ページのURL判定対象の識別、robots.txt / llms.txt の取得先の決定
現在ページのHTML・本文・構造化データ（JSON-LD）・メタタグ（meta robots 等）本文の生HTML可読性、AI利用の制限指定の判定、構造化データ・日付の参考表示
現在ページと同一サイトの robots.txt / llms.txt / ページHTMLAI検索クローラのブロック状況、生HTMLの本文量、llms.txt の有無の確認
ページHTML取得時のHTTPレスポンスヘッダ（X-Robots-Tag、Server 等）AI利用の制限指定の判定、CDNの種別の参考表示
ページの応答時間・HTMLサイズの目安ページの軽さの参考表示

本拡張機能は、氏名・メールアドレス・パスワード・フォーム入力内容などの個人を特定できる情報を取得しません。Chromeの閲覧履歴APIにもアクセスしません。判定対象ページのURLは結果の識別とセッション内キャッシュにのみ使います。また、代表的な管理画面パスや localhost など、判定に適さないページは自動的に判定対象外（無判定）として扱います。

3. 情報の保存

判定結果（バッジ色、判定3項目の状態、参考情報）は、Chromeのセッションストレージ（chrome.storage.session）に一時的に保存されます。これは同じページ・同じサイトを短時間に何度も再取得しないためのキャッシュであり、ブラウザを閉じると自動的に消去されます。この情報はあなたの端末内にのみ存在し、外部には送信されません。

4. クリップボードへの書き込み

パネルの「事実をコピー」ボタンを押した場合に限り、画面に表示されている判定結果をテキスト（Markdown）としてクリップボードへ書き込みます。書き込むのはあなたが押したときだけで、クリップボードの読み取りは行いません。書き込んだ内容が外部へ送信されることもありません。

5. 情報の第三者提供・外部送信

本拡張機能は、読み取った情報や判定結果を、当社を含むいかなる第三者にも送信・提供・販売しません。外部のAPIやアナリティクスサービスとの通信も行いません。本拡張機能が行うネットワーク通信は、判定対象サイト自身の robots.txt・llms.txt・ページHTMLの取得に限られます。

6. 権限（パーミッション）について

本拡張機能が要求する権限と、その目的は以下のとおりです。

権限目的
activeTab利用者がツールバーから明示的に再判定・確認するとき、表示中ページへアクセスするため
scriptingページ構造を読み取る小さなスクリプトを一時的に実行するため
storage判定結果をセッション内で一時キャッシュするため
host_permissions（全サイト）読み込みが完了した判定対象ページを自動判定し、そのサイト自身の robots.txt / llms.txt / ページHTML を取得するため（取得先は判定対象サイトに限定）

7. 変更について

本ポリシーは、機能の変更や法令の改正に応じて更新されることがあります。重要な変更がある場合は、本ページ上で最終更新日を改めてお知らせします。

8. Chrome ウェブストアの限定使用要件

本拡張機能による情報の使用は、Chrome ウェブストアのユーザーデータに関するポリシー（限定使用要件を含む）に準拠します。

Privacy Policy (English)

Last updated: July 31, 2026

Summary: This extension does not collect, store, or transmit any personal data. All analysis happens entirely within your browser. No data is ever sent to any external server, and there is no analytics or tracking.

About. "AI対応チェッカー by 3PT" (AI Readiness Checker) is a tool that shows, via a toolbar badge, whether the page you are viewing is prepared to be read by generative AI crawlers (ChatGPT, Claude, Perplexity, Gemini, etc.). It is provided by Third Party Trust Inc. (3PT).

Information processed. To evaluate eligible HTTPS pages after they finish loading, the extension reads the page URL, its HTML/text/structured data (JSON-LD)/meta tags, the same site's robots.txt, llms.txt, and page HTML, the HTTP response headers of that page request (such as X-Robots-Tag and Server), plus a rough measure of response time and HTML size. It does not read personally identifiable information (names, emails, passwords, or form input) and does not access Chrome's browsing-history API. The evaluated URL is used only to identify and cache the result within the current browser session. Pages unsuitable for evaluation (e.g. common admin paths and localhost) are automatically excluded.

Storage. Evaluation results are cached temporarily in Chrome session storage (chrome.storage.session) to avoid re-fetching the same page or site repeatedly, and are cleared automatically when the browser closes. This data stays on your device only.

Clipboard. Only when you press the "Copy facts" button, the extension writes the on-screen results to your clipboard as Markdown text. It never reads the clipboard, and the copied text is not transmitted anywhere.

No sharing or transmission. The extension does not send, share, or sell any read information or results to any third party, including 3PT. It performs no communication with external APIs or analytics services. Its only network requests are to fetch the evaluated site's own robots.txt, llms.txt, and page HTML.

Limited Use. The use of information received by this extension complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Permissions. activeTab (access the visible page when you explicitly open or re-run the checker), scripting (temporarily run a small script to read page structure), storage (session-only cache of results), and host permissions (automatically evaluate eligible loaded pages and fetch that same site's robots.txt / llms.txt / page HTML).
